## Keep the format simple

An article starts with a title, a short summary, and a body. Headings, links,
lists, quotes, tables, and code use ordinary Markdown.

> The content should remain useful with JavaScript disabled.

| Part | Responsibility |
| --- | --- |
| Markdown | Words, links, and local images |
| Astro | Static HTML and optimized assets |
| Git | History and review |

To publish a finished draft, set `status: published` and add a `publishedAt`
date in `YYYY-MM-DD` form. Run the validation gate and open a pull request.
